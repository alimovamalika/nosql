Embedding

Связанные данные хранятся внутри документа студента.

contact: { city, email }
  • Быстрое чтение
  • Нет дополнительного запроса
  • Удобно для контактных данных
🔗

Referencing

Данные курса хранятся отдельно и связываются по ID.

courseIds: [501, 502, 503]
  • Меньше дублирования
  • Удобно для N:M
  • Используется $lookup

MongoDB запросы

Dot notation

db.students.find({
    "contact.city": "Almaty"
})

$all

db.students.find({
    skills: {
        $all: ["Java", "MongoDB"]
    }
})

$lookup

db.students.aggregate([
    {
        $lookup: {
            from: "courses",
            localField: "courseIds",
            foreignField: "_id",
            as: "courses"
        }
    }
])
