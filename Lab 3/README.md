Медицинский центр — вариант 7

О проекте

Веб-сайт медицинского центра, созданный в рамках лабораторной работы №3 по дисциплине «Нереляционные базы данных (NoSQL)».

Вариант

Вариант 7 — Медцентр

* База данных: clinicDB
* Коллекция: doctors

Структура данных

Для врачей используются следующие поля:

* name — имя врача
* speciality — специальность
* experience — опыт работы
* rating — рейтинг
* languages — языки
* contact — контактная информация

Технологии

* HTML5
* CSS3
* MongoDB
* MongoDB Compass / mongosh
* Visual Studio Code
