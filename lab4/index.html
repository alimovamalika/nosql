03

Index Performance

До индекса

COLLSCAN

MongoDB просматривает документы коллекции для поиска подходящих записей.

totalDocsExamined 30
totalKeysExamined 0
VS

После индекса

IXSCAN

MongoDB использует индекс для поиска подходящих документов.

totalDocsExamined 10*
totalKeysExamined 10*

* Значения являются примером. В отчёте необходимо указать реальные значения из explain("executionStats").

04

Вывод

В лабораторной работе были изучены Aggregation Pipeline, операторы $match, $project, $group, $sort, $limit, $unwind и $lookup.

С помощью explain("executionStats") выполнено сравнение COLLSCAN и IXSCAN. Индексы позволяют уменьшить объём просматриваемых данных, однако требуют дополнительного места и времени на обновление индекса.

При создании составных индексов необходимо учитывать структуру реальных запросов и принцип ESR: Equality → Sort → Range.
