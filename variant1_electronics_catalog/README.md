# Каталог электроники с быстрым поиском — Вариант 1

Учебный мини-проект по дисциплине «Проектирование и применение NoSQL-технологий». Используется MongoDB и Python.

## Возможности
- CRUD: создание товара, чтение по ID, изменение цены и удаление.
- Поиск по названию и бренду.
- Фильтрация по категории, цене, бренду и характеристикам.
- Aggregation Pipeline: средняя цена и количество товаров по категориям.
- Индексы по категории+цене, бренду и текстовому поиску.
- Анализ выполнения запроса через `explain()`.

## Структура
- `src/catalog.py` — логика каталога и демонстрационные запросы.
- `scripts/seed.py` — повторное заполнение базы 37 синтетическими товарами.
- `tests/test_catalog.py` — тесты структуры тестовых данных.
- `docs/ADR.md` — архитектурное решение.
- `docs/report.md` — текст отчёта.
- `docs/presentation.md` — содержание презентации.
- `.env.example` — пример конфигурации без секретов.

## Требования
- Python 3.10+
- MongoDB Community Server, запущенная локально или удалённо
- pip

## Запуск
1. Установить зависимости: `python -m pip install -r requirements.txt`
2. Убедиться, что MongoDB запущена на `mongodb://localhost:27017`.
3. Заполнить базу и создать индексы: `python -m scripts.seed`
4. Выполнить демонстрационные запросы: `python -m src.catalog`
5. Запустить тесты: `python -m unittest discover -s tests -v`

При использовании другого адреса MongoDB задайте переменную окружения `MONGO_URI`. Не помещайте пароли и токены в GitHub.

## Access Patterns
1. Поиск по названию/бренду — высокий приоритет; список совпадений.
2. Список товаров категории — высокий; товары категории.
3. Фильтр категории и максимальной цены — высокий; товары по возрастанию цены.
4. Диапазон цены — высокий; товары между min и max.
5. Поиск товаров бренда — средний; товары указанного бренда.
6. Фильтрация по характеристике — средний; например, беспроводные наушники.
7. Средняя цена и число товаров по категориям — средний; агрегированная статистика.
8. Товары с низким остатком — средний; список для пополнения склада.
9. Получение товара по ID — высокий; одна карточка.
10. Изменение/удаление товара — средний; подтверждение изменения.

## Демонстрационные запросы
В `src/catalog.py` показаны не менее 8 запросов: поиск по слову, фильтр ноутбуков по цене, средняя цена по категориям, количество товаров по категориям, низкий остаток, характеристика wireless, фильтр по бренду и цене, `explain()` для оценки плана выполнения.

## Важное замечание
Результаты выполнения запросов и тестов необходимо получить в своей среде с запущенной MongoDB. В отчёте не следует утверждать, что замеры производительности уже проведены, если вы их фактически не запускали.
